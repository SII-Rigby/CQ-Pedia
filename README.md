# 重庆话正音词典

**重庆话正音词典**是一个面向重庆话学习、记录和查考的在线词典。网站收录重庆话词条、拼音、词性、释义、异体写法、例句和普通话译文，并提供搜索、索引和说明文档。

🔗 网址： [cqpedia.cn](https://cqpedia.cn/)

## 怎么查词

打开网站后，首页会显示“每日十词”。如果你想查某个词，直接在搜索框输入内容即可。

搜索支持：

- 词目，例如“雄起”“安逸”。
- 拼音，例如 `xiong2 qi3`。
- 异体写法，例如某些俗写、同词异形。
- 释义关键词，例如“加油”“便宜”“膝盖”。

输入时结果会自动更新；如果搜索框为空，页面会回到“每日十词”。

## 怎么看词条

每张词条卡一般包含：

- **词目**：推荐使用的写法。
- **词性**：如名词、动词、形容词、助词等。
- **拼音**：按本站的重庆话拼音方案标注。
- **异体写法**：常见俗写、别写或同词异形。
- **释义**：词义说明，可能有多条。
- **例句**：重庆话原句、拼音和普通话译文。
- **注**：补充说明、用法提示或辨析。

## 必读文档

点击页面右上角的 **“必读”**，可以阅读四份说明：

- **重庆方言音系介绍**：了解本站采用的语音背景。
- **重庆话拼音方案**：查看声母、韵母、声调和拼写规则。
- **重庆话的吞音与连读**：了解自然会话中的弱化、省音、同化与合音现象。
- **使用说明**：快速了解本站各项功能。

如果你第一次使用本站，建议先看“重庆话拼音方案”，再查词条。

## 索引

点击搜索框右侧的筛选按钮，可以按分类浏览词条。

- **声母索引**：按词条拼音开头的声母查看。
- **词性索引**：按名词、动词、形容词等词性查看。
- **专题索引**：按主题查看词条，例如“四字词语”“身体部位”“手部动作”“性格”“外貌”“神态”“动物称呼”等。

点选索引项后，页面会显示对应词条；也可以继续输入搜索词，在当前索引范围内搜索。

“四字词语”由前端根据 `data/entries.json` 自动筛选，词目里的儿化标记不计入字数，例如 `怪眉日眼_儿` 归入四字词语。其他专题维护在 `data/topic-indices.json`，新增词条后把词条 id 加入对应专题即可。

## 反馈

点击页面右上角的 **“反馈”** 可以提交两类内容：

- **反馈问题**：指出词条错误、网站问题、拼音/音系问题或改进建议。
- **贡献词条**：提交你认为应该收录的新词条。

反馈时请尽量写清楚相关词条、问题描述、建议改法和你的联系方式。这样后续核对和修订会更方便。

## 本地预览

如果你下载了本项目，不能直接双击 `index.html` 预览，因为浏览器可能会阻止读取词条数据。可以运行：

```powershell
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/
```

## 生成词条页

每个词条的独立页面由 `data/entries.json` 自动生成，不需要手写维护。更新词条数据后运行：

```powershell
python scripts/build_entry_pages.py
```

脚本会生成 `/items/cq-xxxxx/index.html` 和 `sitemap.xml`，用于分享单个词条链接和搜索引擎收录。
