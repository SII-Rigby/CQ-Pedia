# 本站介绍

**CQ-Pedia 重庆话正音词典**，收录以重庆话为主的川渝方言词汇，备读音、释义、例句与用法，供查阅、学习，也为老言子儿留一处安身之地。本站现有词条搜索、每日十词、声母与词性索引、专题索引、示例音频、拼音方案、音系说明及反馈问卷等功能。词条仍将陆续增补，例句、插图、读音与专题亦会渐次完善。

**CQ-Pedia 重庆话音典**，目前已收录5000+个汉字，敬请查阅。

词条繁多，难免疏阙。若知某词写法、读音、用例，或发现错漏，敬请透过问卷赐教。**欢迎转与关心川渝方言的朋友。**
