# 重庆方言音系介绍

重庆话属**西南官话・成渝片**，属于官话大家庭，但在声调、个别韵母和常用词上保留了较多自身特色。本文从声母、韵母、声调三方面给出概要，作为本词典的注音依据。

## 一、声母

重庆话主城口音通常有 **22 个声母**（含零声母），主要特征：

- **不区分平翘舌**：普通话的 `zh ch sh r` 与 `z c s` 在重庆话里合流为 `z c s r`（此处 `r` 对应国际音标中 `[z]` 的发音），词典统一拼作 `z c s r`。
- **n / l 不分**：泥母与来母混淆， `n l` 读为 `l`，此外疑母细音字也多演化为 `l`，比如「严」读作 `lian2`。此外，以鼻音韵尾 `n` 收尾的字衔接以 `l` 韵母开头的字时，后字韵母通常转变为 `n`，如「锻炼」标记为 `duan4 lian4`，但在实际发音中「炼」读作 `nian4`。
- **保留疑母 ng，且零声母开口字也并入 ng 母**：如「安」`ngan1`、「藕」`ngou3`。

## 二、韵母

韵母系统与普通话相比有以下要点：

- 普通话的 `ing` 在重庆话中常并入 `in`，`eng` 常并入 `en`。
- 保留部分特色的韵，如`io`（「学」`xio2`），`üu`（「俗」`xuu2`），`iai`（「解」`jiai3`）。
- 存在儿化韵，但儿化方式与普通话有所不同，主要包含 `er ar ier iar uer uar üer üar` 八种儿化韵，且儿化韵尾通常以舌尖抵住上颚中央收束。
- 重庆话拼音方案中的单韵母 `e` 发音为 `[e]` ，与普通话的 `[ɤə]` 差别较大。

## 三、声调

重庆话有 **4 个单字调**，调值大致为：

| 调类 | 调值（五度） | 例字 |
| --- | --- | --- |
| 阴平 | 45 | 妈 ma1 |
| 阳平 | 21 | 麻 ma2 |
| 上声 | 42 | 马 ma3 |
| 去声 | 213 | 骂 ma4 |

> 注：
> 调值在不同年龄、不同区县间略有差异。本词典以**重庆主城中老派口音**为基准。
> 古入声字在重庆话中基本派入阳平调，统一标第 2 调，如「入」`ru2`「六」`lu2`。但也有例外，如「玉」`yu4`，「压」`ya4`。

## 四、连续变调

- 阴平+阴平，后字调值通常变为55，如「撑花儿」`cen1(45) huar1(55)`、「孃孃」`liang1(45) liang1(55)`。
- 阳平+阳平，去声+去声组合的叠词（主要是名词），后字通常变为阴平（用 `原调值-变调值` 记录变调），如「瓶瓶儿」`pin2 pier2-1`、「舅舅」`jiu4 jiu4-1`。
