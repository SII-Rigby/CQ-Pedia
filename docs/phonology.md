# 重庆方言音系介绍

重庆话属**西南官话・成渝片**，属于官话大家庭，但在声调、个别韵母和常用词上保留了较多自身特色。

本文从声母、韵母、声调和若干口语语音现象几方面给出概要，作为本词典记录读音时的背景说明。若需要查具体拼写，请参看《重庆话拼音方案》。

## 一、声母概况

重庆话主城口音通常有 **22 个声母**（含零声母）。与普通话相比，主要有以下特征：

- **不区分平翘舌**：普通话的 `zh ch sh r` 与 `z c s` 在重庆话里合流为 `z c s r`（此处 `r` 对应国际音标中 `[z]` 的发音）。词典统一拼作 `z c s r`。
- **n / l 不分**：泥母与来母混淆，`n l` 读为 `l`；此外，疑母细音字也多演化为 `l`，比如「严」读作 `lian2`。以鼻音韵尾 `n` 收尾的字衔接以 `l` 韵母开头的字时，后字韵母通常转变为 `n`，如「锻炼」标记为 `duan4 lian4`，但在实际发音中「炼」读作 `nian4`。
- **保留疑母 `ng`，且零声母开口字也并入 `ng` 母**：如「安」`ngan1`、「藕」`ngou3`。但对于不同韵腹的开口字，疑母的存留倾向也有差异，比如「我」「屙」等 `o` 韵腹的字在重庆市区中老派口音中就已经基本不保留（或添加）疑母 `ng`，普遍演化成 `wo` 的发音（当然保留疑母发成 `ngo` 也并非错音），但 `ai ao an en ou` 等韵的字在中老派口音中普遍保留（或添加）疑母 `ng`，而在中新派倾向于将疑母与零声母在语流中处理成条件变体（比如只在前字韵尾是 `ng` 时顺带添加疑母）。

具体声母表请参看《重庆话拼音方案》。

## 二、韵母概况

重庆话韵母系统与普通话相比，主要有以下要点：

- 普通话的 `ing` 在重庆话中常并入 `in`，`eng` 常并入 `en`。
- 保留部分古韵，如 `io`（「学」`xio2`）、`üu`（「俗」`xuu2`）、`iai`（「解」`jiai3`）、`ue`（「国」`gue2`）。
- 重庆话拼音方案中的单韵母 `e` 发音为 `[e]`，与普通话的 `[ɤə]` 差别较大。
- 存在儿化韵，但儿化方式与普通话有所不同，主要包含 `er ar ier iar uer uar üer üar` 八种儿化韵，且儿化韵尾通常以舌尖抵住上颚中央收束。
- 普通话 `un` 与 `d t l z c s` 拼合的字，重庆话通常省去介母 `u`，发成 `en` 的音，如「吞」`ten1`、「村」`cen1`。而与 `g k h zh ch sh` 相拼的字，在重庆话中通常保留介母 `u`，如「滚」`gun3`、「春」`cun1`。
- 重庆话保留 `n / l` 与 `ui` 相拼时的介母，如「内」`lui4`、「雷」`lui2`。
- 韵书中 `m` 与 `ou` 相切的字在重庆话中韵尾通常鼻音化变成 `mong`，如「某」`mong3`、「茂」`mong4`、「贸」`mong4`。口语中，「皱」`zong4`字也有这个趋势。

具体韵母表请参看《重庆话拼音方案》。
儿化的发音也请参看《重庆话拼音方案》。

## 四、连续变调

阳平 + 阳平、去声 + 去声组合的叠词（主要是名词），后字通常变为阴平。本词典用 `原调-变调` 记录变调，例如：

- 「瓶瓶儿」`pin2 pier2-1`
- 「舅舅」`jiu4 jiu4-1`

## 五、声调的条件变体

阴平 + 阴平组合的合成词，后字调值通常变为 55，如「撑花儿」`cen1(45) huar1(55)`、「孃孃」`liang1(45) liang1(55)`。

上声在合成词、语流中作为前字时，调值常变为 44，如「老人」`lao3(44) ren2(21)`、「马起脸」`ma3(44) qi3(44) lian3(42)`。

去声在合成词、语流中作为较轻、较短促的音节时，调值常常由 213 压缩为 22 或 23 甚至与阳平 21 混淆。如「分量」 `fen4(213) liang4(22/23)`、「漱口」`su4(22/21) kou3(42)`。

⚠️ 目前总结出以上三条较为通用的规律，在实际语流中还有更多难以总结的复杂声调变化规则。

## 六、末字双元音化

在口语中，某些韵母的字位于词尾、句尾时，尤其是在拖长发音时，单个元音会趋于不稳定，其后方会补充上一个新的元音。发生这种现象的韵母主要如下：

| 韵母 | 原发音 | 双元音化发音 | 例 |
| --- | --- | --- | --- |
| i | [i] | [iɪ] | 你这个工作好吃皮[pʰiɪ21]！ |
| u | [ʋ] | [ʋo] | 不，不，不[pʋo21]。他说的不作数[sʋo213]。 |
| ü | [y] | [yɪ] | 我的母校在沙坪坝区[tɕʰyɪ45]。 |
| i* | [ɿ] | [ɿɪ] | 桌子上留了一张纸[tsɿɪ42]。 |
| üu | [ɥu] | [ɥuo] | 他这个人嘿俗[ɕɥuo21]。 |
| in | [in] | [iɪn] | 这完全是两码子事情[tɕʰiɪn21]。 |
| ün | [yn] | [yɪn] | 我的梦想是参军[tɕyɪn45]。 |
| er | [(ɚ)ɭ] | [ɭe]（可以理解为声母卷舌化的 le） | 我想给娃儿[ɭ45]买条狗儿[ɭe21]。 |

> * `zi ci si ri` 的韵

末字双元音化是一种语音细节，不在拼音方案中体现。若想把重庆话掌握得更地道，平时可以多留意这一现象。
