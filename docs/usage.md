# 使用说明

欢迎使用**重庆话正音词典**。本页介绍如何使用本站查词、阅读词条，以及如何参与编辑。

## 一、查词

页面顶部的搜索面板提供四种检索方式：

- **全文查词**：在词目、拼音、释义、例句、备注中同时匹配。
- **词目**：仅在词目与异体写法中匹配。
- **拼音**：仅匹配本词典的拼音方案。
- **释义**：仅在释义文本中匹配。

输入框支持**实时检索**，无需点击「搜索」按钮。

## 二、索引筛选

左侧索引可按标签过滤，例如「常用词」「俗语」「生活」「评价」。点击「全部」恢复显示。

## 三、词条解读

每条词目包含以下字段：

1. **词目**与**词性**。
2. **拼音**：依据本站[拼音方案](#)。
3. **异体写法**（可选）：俗写、同词异形等。
4. **释义**：可有多条，编号显示。
5. **例句**：原句 + 拼音 + 普通话译文。
6. **标签** / **备注**。

## 四、参与编辑

词条数据存放在 `data/entries.json`，文档存放在 `docs/*.md`，均可通过 Pull Request 提交修订。

> 提示：异体写法只在确有可靠来源时填写，宁缺毋滥。

## 五、本地预览

```powershell
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000/`。

## 六、反馈

发现拼写错误、释义偏差或用例不当，请在仓库 issue 区指出，谢谢！
