# 使用说明

欢迎使用**重庆话正音词典**。本站可以用来查询重庆话词条、查看拼音和释义，也可以按索引浏览词条。

## 一、搜索词条

首页搜索框支持实时搜索。输入内容后，页面会自动显示匹配词条。

你可以输入：

- 词目，如“雄起”“要得”“安逸”。
- 拼音，如 `xiong2 qi3`。
- 异体写法，如词条中列出的俗写、别写。
- 释义关键词，如“加油”“便宜”“膝盖”。

如果搜索框为空，页面会显示“每日十词”。

提交搜索后，浏览器本地会保留最近 5 次搜索记录，并在搜索框备选项中显示。

## 二、阅读词条

一张词条卡通常包含以下内容：

1. **词目**：本站推荐展示的写法。
2. **词性**：名词、动词、形容词、助词等。
3. **拼音**：按本站拼音方案标注。
4. **异体写法**：常见俗写、别写或同词异形。
5. **释义**：词义说明；多义词会分条列出。
6. **例句**：重庆话原句、拼音和普通话译文。
7. **注**：补充说明、用法提示或辨析。

## 三、阅读“必读”

点击页面右上角的**“必读”**，可以打开本站说明文档。

- **重庆方言音系介绍**：介绍本站记录重庆话读音时参考的音系背景。
- **重庆话拼音方案**：说明声母、韵母、声调和拼写规则。
- **使用说明**：也就是本页，说明网站的基本使用方法。

如果你不熟悉本站拼音，建议先读“重庆话拼音方案”，再回到词条页面查词。

## 四、使用索引

点击页面右上角的**“索引”**，可以不用输入关键词，直接按类别浏览词条。

索引分为两类：

- **声母索引**：按词条拼音第一个音节的声母归类。
- **词性索引**：按词条词性归类。

点击某个索引项后，页面会显示对应词条。此时如果再输入搜索词，页面会切换为搜索结果。

## 五、反馈问题

点击页面右上角的**“反馈”**，可以提交问题或建议。

反馈问题时，可以说明：

- 哪个词条可能有问题。
- 是词目、拼音、释义、例句、音系说明，还是网站功能问题。
- 你认为应该怎样修改。
- 是否方便留下联系方式。

## 六、贡献词条

在“反馈”窗口中切换到**“贡献词条”**，可以提交新词条建议。

建议尽量填写：

- 词目。
- 拼音。
- 词性。
- 释义。
- 例句。
- 例句拼音和普通话译文。
- 异体写法或备注。

提交内容会作为后续整理和校订的参考。
